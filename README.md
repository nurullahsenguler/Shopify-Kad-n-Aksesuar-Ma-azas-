# 🛍️ Nurullah Aksesuar - Shopify E-Ticaret Mağazası

Yüksek dönüşüm oranına sahip, modern ve minimalist tasarımlı, özel Liquid bileşenleriyle güçlendirilmiş e-ticaret tema projesi.

## 🔗 Canlı Mağaza
* **Mağaza URL:** [nurullah-aksesuar.myshopify.com](https://nurullah-aksesuar.myshopify.com/)

## 🛠️ Kullanılan Teknolojiler ve Mimari
* **Şablon Dili:** Shopify Liquid
* **Stil & Tasarım:** CSS / Özel Bileşenler (%1.6)
* **İşlevsellik:** JavaScript (%23.2)
* **Tema Mimarisi:** Modüler section ve snippet yapıları, özel glassmorphism arayüz elemanları ve optimize edilmiş kullanıcı deneyimi.

## 📂 Depo Yapısı
* `assets/`: Stil dosyaları, JavaScript betikleri ve görseller.
* `blocks/`: Tema blok bileşenleri.
* `sections/`: Mağaza sayfa bölümleri (Hero, Header, Footer, Ürün Listeleri vb.).
* `snippets/`: Tekrar kullanılabilir kod parçacıkları ve özel bileşenler.
* `config/`: Tema ayarları ve şemaları.
* `locales/`: Çoklu dil ve çeviri dosyaları.
