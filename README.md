## ✨ Temel Özellikler ve Geliştirmeler
- **Özel Liquid Bölümleri:** Esnek ana sayfa ve kategori yönetimi için yeniden kullanılabilir, dinamik ve modüler bölümler tasarlandı.
- **Duyarlı / Mobil Öncelikli Tasarım:** Aksesuar alışverişi yapan mobil kullanıcılar için kusursuz ve akıcı bir kullanıcı deneyimi (UI/UX).
- **Gelişmiş Ürün Keşfi:** Müşterilerin aradıkları ürünlere en hızlı şekilde ulaşabilmesi için optimize edilmiş koleksiyon ve arama yapısı.
- **Yüksek Performans:** Hızlı sayfa yükleme süreleri sağlamak ve SEO performansını artırmak için temiz, optimize edilmiş Liquid ve CSS/JS kod tabanı.

## 🛠️ Teknik Altyapı ve Teknoloji Yığını
- **Shopify Liquid:** Mağaza mantığı, dinamik veri akışı ve şablonlama dili.
- **JSON / Schema:** Kolay özelleştirme ve tema paneli yönetimi için gelişmiş tema ayarları.
- **Ön Yüz (Frontend):** HTML5, Modern CSS3, JavaScript (ES6+).
- **Sürüm Kontrolü:** Git & GitHub

## 📂 Depo Mimari Yapısı
- `assets/` -> CSS stilleri, JavaScript dosyaları ve ikonlar
- `config/` -> Tema ayarları ve şema dosyaları (`settings_schema.json`)
- `layout/` -> Ana şablon dosyaları (`theme.liquid`)
- `sections/` -> Özelleştirilebilir sayfa bölümleri
- `snippets/` -> Modüler ve tekrar kullanılabilir küçük kod parçacıkları
- `templates/` -> Sayfa şablonları (Ana sayfa, ürün, sepet vb.)
- `locales/` -> Dil ve çeviri dosyaları
